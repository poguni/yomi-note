1. 프로젝트 개요 #

1.1 출발점 #

「전공·취미 기반 바이브 코딩 앱 아이디어 50선」 문서의 3-4. 일본어 한자 & 읽기(후리가나) 학습기 아이디어에서 출발했습니다.

  • 목표: 일본어 글을 붙여 넣으면 후리가나와 단어 뜻을 보여 주고, 모르는 한자를 단어장에 추가합니다.
  • 원래 핵심 기능: 형태소 분석으로 후리가나 자동 표시(토글), 단어 클릭 시 한국어/영어 뜻과 JLPT 급수 표시, 한자별 획순·음독·훈독 카드와 JLPT 레벨별 필터, 읽기 속도 기록
  • 기술: 브라우저용 형태소 분석기(kuromoji.js) + JMdict 사전 데이터
  • 난이도: ★★★★ (사전 데이터 가공과 용량 관리가 핵심 과제)

1.2 추가 요구 사항 #

번호 요구 사항 반영 결과
1 앱의 한글·영어 이름 5가지 추천 「요미노트 / YomiNote」로 결정 (2장 참고)

3 개인용이므로 GitHub에 올려 간단히 배포, 로그인·DB는 꼭 필요하지 않으면 제외 순수 정적 웹앱으로 구현
4 localStorage 저장, 필요하면 엑셀·워드·PDF로 저장 엑셀·워드·PDF·CSV 내보내기와 JSON 백업·복원 구현

6 (2차) 상단 제목·메뉴 디자인을 세련되게 개선 한 줄 헤더, 세그먼트 메뉴, 선 아이콘으로 재설계
7 (2차) 오른쪽 위 테마 선택 드롭다운(라이트/다크) 테마 저장과 첫 화면 깜박임 방지까지 구현

4. 기술 스택과 구조 #

4.1 기술 스택 #

구분 선택 선택 이유
프레임워크 없음 (Vanilla JS, ES Modules) 빌드 과정 없이 GitHub Pages에 바로 올릴 수 있습니다.
형태소 분석 kuromoji.js 0.1.2 (IPADIC) 브라우저에서 동작하는 가장 검증된 일본어 형태소 분석기입니다.
단어 사전 open-anki-jlpt-decks (JMdict 기반, MIT) JLPT 급수와 영어 뜻이 함께 있어 바로 쓸 수 있습니다.
한자 사전 kanji-data (KANJIDIC2 기반, MIT) 획수·학년·JLPT·음훈·뜻이 정리되어 있습니다.
획순 KanjiVG (CC BY-SA 3.0) 필요한 한자의 SVG만 실행 중에 받아와 용량을 아낍니다.
음성 Web Speech API 무료이며 설치된 OS 음성을 그대로 씁니다.
엑셀 / 워드 SheetJS CE 0.18.5 / docx 8.5.0 내보낼 때만 불러오는 지연 로딩으로 첫 화면을 가볍게 유지합니다.
PDF 브라우저 인쇄 기능 한글·일본어 글꼴을 따로 넣지 않아도 깨지지 않습니다.
저장 localStorage 요구 사항(로그인·DB 없음)에 맞고 단어 수천 개까지 충분합니다.

5. 개발 과정 #

5.1 타임라인 #

단계 작업 결과
1. 환경 조사 사전·라이브러리를 받을 수 있는 경로 확인 개발 환경에서 CDN(jsdelivr·unpkg·cdnjs)과 JMdict 배포처가 막혀 있음을 확인 → npm 레지스트리와 GitHub raw로 대체
2. 데이터 준비 빌드 스크립트 작성, JLPT 단어·한자 데이터 정제 단어 8,017개, 한자 3,122자, 합계 약 650KB
3. 앱 골격 HTML 구조, 디자인 토큰, 모듈 분리 5개 탭(읽기·단어장·한자 카드·읽기 기록·데이터)
4. 핵심 기능 형태소 분석, 후리가나 정렬, 단어 패널, 단어장, TTS, 획순, 내보내기 v1 기능 완성
5. 자동 테스트 Playwright(헤드리스 크롬)로 데스크톱·모바일·다크 모드 시나리오 실행 기능 동작과 다운로드 파일 형식 확인, 화면 캡처 검토
6. 1차 배포 커밋·푸시, 압축 파일 전달 4122495
7. 2차 개선 헤더 재설계, 라이트/다크 테마, README 배포 안내 수정 cf21c87
8. 기능 상담 일본어 → 한국어 번역 기능 구현 방식 검토 9장 로드맵에 반영

5.2 주요 설계 결정 #

  1. 사전 파일을 저장소에 포함(vendoring) CDN을 쓰면 저장소는 가볍지만, 개발 환경에서 검증할 수 없고 CDN 장애에 영향을 받습니다. kuromoji 사전(18MB)과 라이브러리를 vendor/에 넣어 저장소 하나만으로 완결되게 했습니다.

  2. JMdict 전체 대신 JLPT 단어 목록을 기본 사전으로 JMdict 원본은 개발 환경에서 받을 수 없었고, 전체를 넣으면 용량도 큽니다. JMdict 기반의 JLPT 단어 목록(약 8천 개)을 기본으로 쓰고, tools/build-data.mjs --jmdict 옵션으로 일반 단어 약 2만 2천 개를 나중에 합칠 수 있게 했습니다.

  3. 한국어 뜻은 사용자가 직접 입력 공개된 일한 사전 데이터가 없고 JMdict에도 한국어 뜻이 없습니다. 억지로 기계 번역하는 대신 직접 적고, 네이버 사전 링크로 확인하는 흐름을 택했습니다. 이 뜻은 단어장과 내보내기에 그대로 들어갑니다.

  4. PDF는 브라우저 인쇄 기능으로 jsPDF 같은 라이브러리는 한글·일본어 글꼴(수 MB)을 넣어야 글자가 깨지지 않습니다. 인쇄용 HTML을 숨은 iframe에 만들어 인쇄 창을 여는 방식으로 용량 0, 글꼴 문제 0을 달성했습니다.

  5. 내보내기 라이브러리는 지연 로딩 SheetJS(약 860KB)와 docx(약 720KB)는 버튼을 눌렀을 때만 불러와 첫 화면 로딩을 가볍게 유지합니다.

  6. TTS는 문장 단위로 나눠 재생 크롬은 긴 글을 한 번에 읽히면 중간에 끊기는 문제가 있습니다. 문장 단위 큐로 나누면서 지금 읽는 문장 강조 기능도 자연스럽게 얻었습니다.

5.3 핵심 구현 포인트 #

  • 후리가나 정렬: 「食べる / たべる」처럼 표기와 읽기를 받아, 표기를 한자 덩어리와 가나 덩어리로 나눈 뒤 정규식(^(.+?)べる$)으로 읽기에 맞춥니다. 그래서 오쿠리가나를 뺀 한자 부분에만 후리가나가 붙습니다. 맞추지 못하면 단어 전체에 붙이는 방식으로 안전하게 처리합니다.
  • 급수별 후리가나 숨김: 토큰마다 사전에서 JLPT 급수를 찾아 기준보다 쉬운 단어는 <rt>를 숨깁니다. 단어장에서 ‘외웠어요’로 표시한 단어도 숨겨 학습할수록 후리가나가 줄어드는 경험을 만듭니다.
  • 기본형 기준 단어장: 본문의 「撮り」를 눌러도 단어장에는 기본형 「撮る【とる】」로 저장되고, 본문 형태와 활용형은 패널에 따로 보여 줍니다.
  • 획순 애니메이션: KanjiVG SVG의 획(path)마다 getTotalLength()로 길이를 구하고, stroke-dashoffset 전환으로 한 획씩 그립니다. 획 길이에 비례해 그리는 시간을 바꿔 자연스럽게 보이게 했습니다.
  • 테마 깜박임 방지: <head>의 작은 인라인 스크립트가 CSS보다 먼저 저장된 테마를 data-theme에 적용합니다. 다크 모드로 저장했는데 밝은 화면이 잠깐 보이는 현상이 없습니다.

6. 문제 해결 기록 #

문제 원인 해결
CDN과 JMdict 배포처에 접속 불가 개발 환경의 네트워크 정책 npm 레지스트리(kuromoji·SheetJS·docx)와 GitHub raw(JLPT·한자 데이터)로 대체하고, 라이브러리를 저장소에 포함
일부 서버에서 사전 로딩 실패 가능성 .gz 파일을 서버가 미리 풀어서 보내면 kuromoji가 한 번 더 풀다가 오류 발생 kuromoji 로더에 gzip 매직 넘버(1F 8B) 검사를 추가하는 한 줄 패치([yomi-note patch])
읽기에 「(を) とお」 같은 군더더기 원본 CSV의 괄호 표기 빌드 스크립트에서 괄호·물결표·공백 제거
읽기 칸이 비었거나 표기와 뒤바뀐 행 원본 데이터 오류(例: 頂く/いただく) 가나 여부를 검사해 자동 보정
한글 파일명이 ‘download’로 저장됨 일부 환경에서 비ASCII 다운로드 파일명 미지원 yominote-vocab-2026-10-14.xlsx처럼 영문 파일명 사용
CSV를 엑셀에서 열면 한글 깨짐 UTF-8 BOM 없음 파일 앞에 BOM(﻿) 추가
읽기 기록 1회일 때 막대가 화면 전체를 차지 막대 폭을 개수로만 계산 최대 폭 36px로 제한
모바일에서 「요미노트」가 두 줄로 줄바꿈 좁은 화면에서 영문 배지·테마 버튼과 공간 경쟁 제목 줄바꿈 금지, 560px 이하에서 부제·배지 숨김, 430px 이하에서 메뉴 아이콘 숨김
다크 모드에서 선택된 메뉴가 잘 안 보임 배경과 명도 차이가 작음 선택 메뉴 배경색을 별도로 지정

8. 알려진 한계 #

  1. 내장 사전 범위: JLPT 단어 약 8천 개라 고유명사·신조어·전문 용어는 뜻이 나오지 않습니다. (외부 사전 링크로 보완)
  2. 한국어 뜻 자동 제공 없음: 사용자가 직접 입력해야 합니다.
  3. 형태소 분석 단위: 「食べ + ました」처럼 활용 어미가 따로 나뉘어 클릭 단위가 학습자의 감각보다 잘게 쪼개집니다.
  4. 첫 로딩 18MB: 형태소 사전 때문에 처음 열 때 시간이 걸립니다. (이후 브라우저 캐시)
  5. 기기 간 동기화 없음: localStorage는 브라우저마다 따로라서 백업 파일로 옮겨야 합니다.
  6. 획순은 온라인 필요: 한자 카드를 열 때 GitHub에서 SVG를 받아옵니다.
  7. 음성 품질은 기기 의존: OS에 설치된 일본어 음성에 따라 품질이 달라집니다.
  8. JLPT 급수는 비공식: 2010년 이후 공식 목록이 없어 커뮤니티 목록을 기준으로 합니다.

9.2 v1.1 — 바로 체감되는 개선 #

① 일본어 → 한국어 번역

  • 기본: 크롬의 브라우저 내장 번역(Translator API)을 씁니다. API 키·비용 없이 기기 안에서 번역합니다. 지원하지 않는 브라우저에서는 지금처럼 파파고 링크로 대체합니다.
  • 선택: 데이터 탭에 API 키(OpenRouter·Claude·Gemini 등)를 넣으면 AI 번역을 켭니다. 키는 내 브라우저의 localStorage에만 저장하고 저장소에는 절대 올리지 않습니다. 서비스 쪽에서 월 사용 한도를 걸어 두면 안전합니다.
  • AI를 켜면 함께 가능한 기능: 문장별 자연스러운 번역, 문법 해설(「〜ていた」의 의미 등), 단어장 한국어 뜻 자동 채우기, 예문 생성

② 플래시카드와 간격 반복(SRS)

  • 단어장의 단어·한자를 카드로 복습하고 ‘다시 / 어려움 / 알맞음 / 쉬움’으로 답합니다.
  • SM-2 또는 FSRS 알고리즘으로 다음 복습일을 계산해 오늘 복습할 카드를 보여 줍니다.
  • 앞면(표기) ↔ 뒷면(읽기·뜻·예문)에 TTS를 함께 붙이면 듣기 복습도 됩니다.

③ PWA(오프라인·설치)

  • 서비스 워커로 앱 파일과 18MB 사전을 캐시해 지하철에서도 오프라인으로 쓸 수 있게 합니다.
  • manifest.json을 추가해 휴대폰 홈 화면에 앱처럼 설치합니다. 지금의 「読」 아이콘을 그대로 쓰면 됩니다.

④ 한자 카드에 한국 한자음 표시

  • KANJIDIC2에는 한국어 음(예: 漢 → 한)이 들어 있습니다. 빌드 스크립트에 추가하면 「漢 · 한나라 한」처럼 한국 사람에게 가장 익숙한 단서를 카드에 보여 줄 수 있습니다. (훈은 별도 데이터 보완 필요)

⑤ 활용형 묶어 보기

  • 동사·형용사 뒤의 조동사·접미사(ます・た・ない・て 등)를 앞 단어와 묶어 한 덩어리로 보여 줍니다.
  • 패널에는 「食べました = 食べる + ます(정중) + た(과거)」처럼 활용 분해 설명을 붙이면 문법 학습에도 도움이 됩니다.

⑥ 작은 사용성 개선

  • 테마에 ‘시스템 설정 따르기’ 옵션 추가
  • 단어장 태그(예: 「뉴스」, 「소설」)와 여러 항목 한꺼번에 상태 변경·삭제
  • 본문에서 단어를 길게 누르면 바로 단어장에 추가하는 빠른 동작
  • 단어장 항목의 예문을 누르면 그 글로 돌아가는 링크

9.3 v1.2 — 학습 효과를 키우는 기능 #

⑦ 글 난이도·커버리지 분석

  • 분석한 글의 단어를 JLPT 급수별로 집계해 「N5 45% · N4 20% · … · 급외 10%」 막대로 보여 줍니다.
  • 내 단어장의 ‘외웠어요’와 비교해 **「이 글의 87%를 이미 알고 있어요」**를 계산합니다. 읽을 글을 고르는 기준이 됩니다.

⑧ 퀴즈 모드

  • 읽기 맞히기(漢字 → ひらがな 입력), 뜻 맞히기(4지선다), 듣고 고르기(TTS)
  • 한자 쓰기: 캔버스에 손가락으로 쓰고 KanjiVG 획과 비교해 획순·방향을 채점합니다.

⑨ 글 보관함

  • 여러 글을 제목과 함께 저장하고 이어 읽기 위치·읽은 날짜·읽기 속도를 같이 남깁니다.
  • 지금은 마지막 글 하나만 기억하므로, 보관함이 생기면 읽기 기록·커버리지와 연결하기 좋습니다.

⑩ 학습 통계 대시보드

  • 연속 학습일(스트릭), 주간 추가 단어 수, 급수별 단어장 분포, 읽기 속도 추세를 한 화면에 모읍니다.

⑪ 사전 데이터 확장 자동화

  • GitHub Actions에서 jmdict-simplified 최신 릴리스를 받아 build-data.mjs --jmdict로 빌드하고 Pages에 배포합니다. 사전 업데이트가 자동으로 반영됩니다.
  • 단어 수가 늘면 words.json을 첫 글자별로 나눠 필요한 부분만 불러오도록 바꿉니다.

⑫ Anki 내보내기

  • Anki가 바로 가져갈 수 있는 형식(탭 구분 텍스트 또는 .apkg)으로 내보내 기존 학습 도구와 연결합니다.

9.4 v2.0 — 새로운 입력과 확장 #

⑬ 이미지·URL에서 글 가져오기

  • tesseract.js(일본어 학습 데이터)로 교재·만화·메뉴판 사진에서 글자를 뽑아 바로 분석합니다.
  • 웹 기사는 본문만 복사해 붙이는 ‘읽기 모드’ 북마클릿으로 가져옵니다.

⑭ 쉐도잉·발음 연습

  • 문장을 TTS로 듣고 따라 읽으면 음성 인식(Web Speech API, ja-JP)으로 받아 적어 원문과 비교합니다.

⑮ 로그인 없는 동기화

  • 개인용이라는 원칙은 지키면서, 백업 JSON을 GitHub Gist나 Google Drive에 올리고 받는 버튼을 제공합니다. 집 PC와 휴대폰에서 같은 단어장을 쓸 수 있습니다.

⑯ 세로쓰기(縦書き) 보기

  • CSS writing-mode: vertical-rl로 소설·신문처럼 세로로 읽는 모드를 추가합니다. 후리가나도 세로에 맞게 오른쪽에 붙습니다.

YomiNote is a Japanese reading companion for the browser: paste any Japanese text and it adds furigana, English meanings, and JLPT levels through in-browser morphological analysis. Unknown words and kanji go into a personal vocabulary list with their example sentences, backed by animated stroke-order cards, text-to-speech, and reading-speed tracking. It runs entirely client-side with no server or login, and exports your list to Excel, Word, or PDF.
